数据与部署

这个项目怎么跑的

数据加载 posts-data.js 打包了全部 2,340 篇帖子的精简字段（1.4 MB）， 用 <script> 标签加载而非 fetch，因此不受静态托管的跨域限制。
图片来源 路径规则 {postID}_{原文件名}，直接读仓库内的 images/downloaded_posts_images/。GitHub Pages 会发布整个仓库， 所以相对路径在部署后同样有效，不需要配置 CDN。
重新生成数据 改动 posts2/ 下的 JSON 后运行 python build_data.py 重新生成 bundle。字段从 3.7 MB 精简到 1.4 MB。
开启 Pages 仓库 Settings → Pages → Source 选 main 分支、根目录 /。 本页即部署后的首页。

帖子数据与全部图片均为 AI 随机生成，仅用于界面演示，不代表任何真实社区内容。
